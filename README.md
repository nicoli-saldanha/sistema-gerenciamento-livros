# Sistema de Gerenciamento de Livros
Aplicação web desenvolvida para fins acadêmicos com o objetivo de auxiliar usuários no gerenciamento de livros lidos. O sistema permite cadastrar, visualizar e excluir livros, organizando-os por categoria e armazenando as informações em um banco de dados MySQL.

## Tecnologias Empregadas
- HTML5
- CSS3
- JavaScript
- Node.js
- MySQL
